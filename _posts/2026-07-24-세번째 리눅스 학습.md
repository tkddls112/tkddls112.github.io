\## 리눅스(Linux)



리눅스는 윈도우, Mac 등과 같은 운영체제로 많이 사용되지는 않지만 서버가 사용하는 운영체제에서는 리눅스가 점유하고 있어서 보안 공부에 큰 도움이 된다.

\## 셸(Shell)



운영체제는 크게 2가지 수준으로 나뉨

* 유저 레벨 : 사용자가 조작할 수 있는 부분
* 커널 레벨 : 일반 사용자가 조작할 수 없는 부분 (운영체제 영역)



셸이란 사용자가 운영체제와 상호작용할 수 있는 인터페이스를 제공하는 소프트웨어를 의미



셀은 크게 2가지로 나뉨

* Graphical User Interface Shell (GUI Shell) : 일반적으로 사용하는 Windows, MacOS의 검색창 등이 대표적인 GUI Shell
* Command-Line Interface Shell (CLI Shell) : Windows의 CMD와 MacOS의 터미널 등이 대표적인 CLI Shell



셀의 종류 크게 4가지

1. Bourne Shell (sh)은 유닉스 버전 7의 기본 셸이다. 기본적인 프로그램 실행, I/O 명령 실행, 셸 프로그래밍 등을 지원
2. Bourne-Again Shell (bash)은 sh를 대체하기 위해 Brian Fox가 작성한 유닉스 셸입니다. 일반 사용자들이 기본적으로 로그인하면 볼 수 있는 셸

## 로그인과 실행의 차이

로그인은 사용자가 아이디와 비밀번호 등을 입력해 셸을 접속하는 상황이고, 실행은 콘솔 창에서 bash 명령어를 실행하거나 스크립트 내부에서 bash를 호출하는 것을 의미한다.
3. ash \& dash Shell은 bash보다 경량화된 유닉스 셸
4. zsh Shell은 Bourne Shell을 기반으로, bash, ksh 등의 다양한 셸의 장점을 모아 만든 확장형 셸이다.

\## 터미널(Terminal)



터미널은 CLI 셀을 GUI 셀 위에서 사용할 수 있도록 하는 프로그램이다.
