## 리눅스(Linux)



리눅스는 윈도우, Mac 등과 같은 운영체제로 많이 사용되지는 않지만 서버가 사용하는 운영체제에서는 리눅스가 점유하고 있어서 보안 공부에 큰 도움이 된다.

## 셸(Shell)



운영체제는 크게 2가지 수준으로 나뉨

* 유저 레벨 : 사용자가 조작할 수 있는 부분
* 커널 레벨 : 일반 사용자가 조작할 수 없는 부분 (운영체제 영역)



셸이란 사용자가 운영체제와 상호작용할 수 있는 인터페이스를 제공하는 소프트웨어를 의미



셀은 크게 2가지로 나뉨

* Graphical User Interface Shell (GUI Shell) : 일반적으로 사용하는 Windows, MacOS의 검색창 등이 대표적인 GUI Shell
* Command-Line Interface Shell (CLI Shell) : Windows의 CMD와 MacOS의 터미널 등이 대표적인 CLI Shell



셀의 종류 크게 4가지

1. Bourne Shell (sh)은 유닉스 버전 7의 기본 셸이다. 기본적인 프로그램 실행, I/O 명령 실행, 셸 프로그래밍 등을 지원
2. Bourne-Again Shell (bash)은 sh를 대체하기 위해 Brian Fox가 작성한 유닉스 셸입니다. 일반 사용자들이 기본적으로 로그인하면 볼 수 있는 셸

## 로그인과 실행의 차이

로그인은 사용자가 아이디와 비밀번호 등을 입력해 셸을 접속하는 상황이고, 실행은 콘솔 창에서 bash 명령어를 실행하거나 스크립트 내부에서 bash를 호출하는 것을 의미한다.
3. ash \& dash Shell은 bash보다 경량화된 유닉스 셸
4. zsh Shell은 Bourne Shell을 기반으로, bash, ksh 등의 다양한 셸의 장점을 모아 만든 확장형 셸이다.

## 파일과 디렉터리



파일은 의미가 있는 정보를 모아둔 논리적인 단위. 파일의 맨 앞에 특정한 바이트로 해당 파일의 종류를 나타내는 값을 매직 넘버 혹은 파일 시그니쳐라 부른다.



디렉터리는 파일을 분류하기 위해 사용하는 네이스페이스이며 Windows와 같은 환경에서는 주로 폴더라고 부른다.



디렉터리에는 2가지로 나뉨

1. 하위 디렉터리 : 디렉터리는 다른 디렉터리 혹은 파일을 내부에 포함
2. 상위 디렉터리 : 하위 디렉터리를 포함하는 디렉터리



디렉터리와 파일들은 일반적으로 트리 구조를 형성



-----



## 디렉터리 경로 확인 (pwd)

pwd는 print working directory의 약자로 현재 작업 중인 디렉터리를 출력하는 명령어

cd는 change directory의 약자로 디렉터리 경로를 변경할 때 사용

상위 디렉터리의 경로를 ### ../라 부름.



## 디렉터리 및 파일 확인 (ls)

ls는 list segements의 약자로 파일 목록을 표시

ls의 구체적인 옵션들은 ls --help를 이용해 확인할 수 있음.



d rwxr-x---  4 user user 4096 NOV 4 16:16 .

d는 파일 종류

rwxr-x---는 파일 권한

1은 하드 링크 개수

user은 파일 소유자(유저)

user은 파일 그룹

4096은 파일 용량

NOV 4 16:16는 변경 일자

.은 파일 이름



## 디렉터리 생성(mkdir)

mkdir은 make directory의 약자로 새로운 디렉터리를 생성



## 디렉터리 삭제(rmdir)

rmdir은 remove directory의 약자로 생성된 디렉터리를 삭제



## 파일 생성(touch)

touch는 파일 생성 목적

touch \[파일 이름]로 새로운 파일을 생성하며, 이 때 파일의 크기는 0이다.



## 파일 읽기 및 쓰기(cat, head, tail)

touch로는 파일에 내용을 읽거나 쓸 수 없다.

cat는 concatenate에서 유래한 명령어로 단어의 뜻에서 살펴볼 수 있듯이 해당 명령은 두 내용을 연결한다는 뜻이다.

cat > \[파일 이름]을 입력하면 터미널의 입출력과 파일을 연결하게 되며 터미널의 입력이 파일에 기록됨



## 파일 이동 및 복사(mv, cp)



mv는 move의 약자로 파일의 경로를 변경한다.

mv \[옵션] \[현재 경로] \[변경할 경로]와 같이 사용

옵션 ↓



|-b|변경하고자 하는 경로에 동일한 파일명이 존재하면 백업 파일을 생성|
|-|-|
|-f|변경하고자 하는 경로에 동일한 파일명이 존재하면 사용자에게 덮어씌우기 여부를 묻지 않고 강제로 덮어씀|
|-i|변경하고자 하는 경로에 동일한 파일명이 존재하면 사용자에게 덮어씌우기 여부를 확인|
|-n|변경하고자 하는 경로에 동일한 파일명이 존재하면 파일을 이동하지 않음|



cp는 copy의 약자로 파일을 복사한다.

cp \[옵션] \[현재 경로] \[복사할 경로]와 같이 사용

디렉터리에 cp를 사용하기 위해서는 -r 옵션을 부여해야 함

옵션 ↓

|-r|하위 디렉터리의 내용까지 모두 복사|
|-|-|
|-f|복사하고자 하는 경로에 동일한 파일명이 존재하면 사용자에게 덮어씌우기 여부를 묻지 않고 강제로 덮어씀|
|-i|복사하고자 하는 경로에 동일한 파일명이 존재하면 사용자에게 덮어씌우기 여부를 물음|
|-p|파일 복사 시 모든 권한 정보를 함께 복사|



## 파일 삭제(rm)

rm은 remove의 약자로 생성된 파일을 삭제

## 파일 링크



### 하드 링크와 심볼릭 링크



링크 파일이란 어떤 파일들의 정보를 직, 간접적으로 연결한 파일을 의미

윈도우의 바로 가기는 대표적인 링크 파일의 예시



운영체제는 파일들을 생성하고, 읽고, 쓰기 위해 관리하는 시스템이 필요하며 이를 파일 시스템이라 부른다.

리눅스의 파일 시스템은 각 파일들을 inode라는 메타 데이터로 관리하며 각 파일은 고유한 inode를 가지고 있다.

참조 횟수(refcount)는 inode를 참조하고 있는 파일의 개수를 의미



### 하드 링크

하드 링크란 생성되는 파일의 inode를 링크하고자 하는 파일에 직접 연결하는 방식



### 심볼릭 링크

심볼릭 링크 또는 소프트 링크란 절대 경로 또는 상대 경로로 된 다른 파일들을 참조하는 파일이며, Windows의 바로가기와 유사함.



## 파일 탐색 (find)

find는 find 뜻 그래도 파일을 탐색하는 명령어

find \[옵션] \[탐색 시작 경로] \[표현식 1] \[표현식 2]...으로 사용
