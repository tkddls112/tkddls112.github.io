**Shell**



셀이란 유저가 리눅스 시스템을 이용할 수 있는 인터페이스이다.

리눅스에서 터미널을 실행시킬때 단축키를 사용할 수 있는데 ctrl + alt + T를 누르면 터미널이 바로 실행된다.

1.sudo apt update는 apt 명령어로 소프트웨어 패키지 목록을 업데이트해준다.

2\. sudo apt upgrade는 리눅스에 설치된 소프트웨어 패키지의 버전을 업그레이드해준다. 하지만 오래된 버전은 보안 문제가 생길 수 있으니 주기적으로 업그레이드를 해줘야한다.

3\. id는 현재 유저 ID를 출력

4\. pwd는 print working directory의 줄임말이고, 현재 작업 중인 디렉토리의 경로를 출력

5\. ls는 List의 줄임말이고, 디렉토리 목록을 출력

6\. cd는 change directory의 줄임말로 디렉토리를 변경해줌

이 명령어는 절대 경로와 상대 경로를 알아야함.

7\. mkdir은 make directory의 줄임말로 디렉토리를 생성해줌

8\. touch는 비어 있는 새로운 파일은 생성

9\. mv는 move의 줄임말로 파일이나 디렉토리의 위치를 옮겨줌.

이름을 변경도 해줌

10\. rm은 remove의 줄임말로 파일이나 디렉토리를 삭제

11\. cat는 파일의 내용을 출력하는 명령어

12\. file은 파일의 유형을 출력하는 명령어

13\. echo는 셀에 유저가 입력한 텍스트를 출력

14\. cp는 copy의 줄임말로 파일이나 디렉토리를 복사

15\. grep는 전체에서 특정 문자열을 찾을 때 사용

16\. man은 manual의 줄임말로 특정 명령어의 메뉴얼을 보여주는 명령어

메뉴얼은 명령어 사용법, 옵션, 예제 등 정보를 담고있음

17\. curl은 client URL의 줄임말로 서버에 데이터를 보내거나 서버로부터 데이터를 받는 데이터 전송 명령어 (워게임에서 주로 사용)

curl 명령어의 주요 옵션

* \-o file : 전송 받은 데이터를 파일에 저장
* \-i : 결과 값에 HTTP 응답 헤더를 포함
* \-X "method" : HTTP 요청 메소드를 지정
* \-d "key=value" : HTTP POST 메소드로 데이터를 전송



**와일드카드**



와일드카드는 리눅스에서 임의의 다른 문자를 나타낼 수 있는 특수 문자들을 의미



1. ? 는 a\~z, 0\~9 범위 내 임의의 1개 문자로 대체
2. \*은 a\~z, 0\~9 범위 내 임의의 0개 이상 문자로 대체
3. \[]는 \[문자1-문자2] 혹은 \[문자1,문자2,...] 형태로 범위 지정



**리다이렉션**



리다이렉션은 모니터에 나타나는 표준 출력 혹은 키보드로 입력하는 표준 입력을 다른 곳으로 변경하는 작업

명령어 > 파일

명령어 표준 출력을 파일로 변경

파일이 없으면 새로 만들고, 있으면 덮어씀



명령어 >> 파일

명령어 표준 출력을 파일로 변경

파일이 없으면 새로 만들고, 있으면 이어서 씀



명령어 < 파일

명령어 표준 입력을 파일로 변경

파일로부터 표준 입력을 받아 명령어를 수행



**파이프**



파이프는 리다이렉션의 한 형태로, 명령어 결과 표준 출력을 다른 명령어의 표준 입력으로 보낼 때 사용



**유저와 그룹**



리눅스의 각 유저는 이름과 고유한 사용자 ID를 가지고, 그룹은 여러 유저가 속할 수 있는 그룹으로 그룹 이름과 고유한 그룹ID를 가짐



**파일 및 디렉토리 권한**



각 파일과 디렉토리는 소유자와 소유 그룹을 가지고 있음

소유자는 세 종류의 접근 권한이 존재

* 읽기 : 파일 또는 디렉토리의 내용을 볼 수 있게 허용
* 쓰기 : 파일 또는 디렉토리의 내용을 수정하거나 삭제하는 것을 허용
* 실행 : 파일이 프로그램인 경우 실행할 수 있게 허용. 디렉토리의 경우 디렉토리 내용에 접근 가능하게 허용
* r : 소유자가 파일 또는 디렉토리에 읽기 권한을 가짐
* w : 소유자가 파일 또는 디렉토리에 쓰기 권한을 가짐
* x : 소유자가 파일 또는 디렉토리에 실행 권한을 가짐

/bin

일반 유저가 사용할 수 있는 기본적인 명령어나 프로그램을 담고 있는 디렉토리

/boot

시스템 부팅에 필요한 파일들을 담고 있는 디렉토리

/dev

리눅스에서는 컴퓨터에 부착된 물리적인 장치들을 디바이스 드라이버를 거쳐 파일 형태로 접근 가능 그러한 장치들을 나타내는 파일들을 담고 있는 디렉토리

/etc

운영체제나 운영체제 위에서 동작하는 서비스의 설정 파일들을 담고 있는 디렉토리

/home

각 일반 유저의 홈 디렉토리를 담고 있는 디렉토리. 일반 유저들은 각기 자신만의 홈 디렉토리를 가짐

/lib

시스템에 필요한 라이브러리 파일들을 담고 있는 디렉토리. /bin에 존재하는 프로그램이 필요로 하는 동적 라이브러리 파일이 /lib 디렉토리에 존재

/opt

소프트웨어 패키지들을 담는 디렉토리

/proc

리눅스 커널 자원에 접근할 수 있는 파일과 프로세스를 나타내는 파일

/root

root 유저의 홈 디렉토리

/sbin

/bin 디렉토리와 마찬가지로 기본적인 유저 명령어나 프로그램을 가지고 있는 디렉토리

/tmp

유저나 프로그램이 임시로 파일을 생성해야할 때 사용할 수 있는 디렉토리

/usr

사용자 바이너리, 문서, 라이브러리, 헤더 파일 등을 담고 있는 디렉토리

/var

프로그램이나 시스템이 실시간으로 가변적인 파일을 사용하고 저장해야 할 때 활용하는 디렉토리
