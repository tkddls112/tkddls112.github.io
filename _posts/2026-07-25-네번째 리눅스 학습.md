\## 프로세스

프로세스는 컴퓨터에서 실행되고 있는 프로그램이다.

생성된 프로세스는 CPU에서 실행되며 만약 여러 프로세스가 동시에 실행되는 경우 운영체제가 실행 순서를 조절하여 동작 시킴.



프로세스는 크게 5가지의 상태를 가짐

* 생성 : 프로세스가 생성되는 중
* 실행 : 프로세스가 CPU를 점유하여 실제로 명령어들을 실행하는 중
* 준비 : 프로세스가 CPU를 점유하기 위해 대기하고 있는 상태
* 대기 : 프로세스가 입출력 대기 혹은 리소스에 접근 불가 등의 이유로 요청한 일을 수행할 수 없어 CPU를 양도하고 선수 작업이 완료되기를 대기하는 상태
* 종료 : 프로세스가 종료되는 중



\## 리눅스 프로세스

리눅스의 프로세스는 PID와 PPID를 가짐

PID는 현재 프로세스의 아이디를 의미

PPID는 부모 프로세스의 아이디를 의미



리눅스는 새로운 프로세스를 생성할 때 fork()를 사용

만약 fork()로 프로세스를 생성할 경우 원본 프로세스를 부모 프로세스, 생성되는 프로세스를 자식 프로세스라고 부름

fork()한 후 자식 프로세스에서 exec()를 사용하면, 프로세스를 복제한 후 자식 프로세스의 내용을 다른 실행파일의 내용으로 덮어씀



\## 프로세스 관리



\### 프로세스 확인(ps, htop)

ps는 process state의 약자로 현재 실행중인 프로세스의 상태를 보여줌

ps \[옵션]



\### 포그라운드와 백그라운드(fg, bg, jobs)

포그라운드 프로세스는 사용자와 직접적으로 상호작용하며 실행되는 프로세스이다.

백그라운드 프로세스는 사용자와 직접적으로 상호작용하지 않고 실행되는 프로세스이다.



\### 프로세스 종료(kill, pkill)

kill - \[signal] \[PID]로 사용



\### 프로세스 우선 순위(nice)

nice 명령어는 프로세스의 nice 값을 설정하여 우선 순위를 결정

nice -n \[nice] \[프로세스 이름]
